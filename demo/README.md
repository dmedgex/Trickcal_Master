# 金蜡笔日记 · UI 原型

可点击的 HTML 原型，用于确认新 App 的信息架构与视觉方向。**不是最终代码**，仅用于讨论。

## 打开方式

需要本地 HTTP 服务（直接双击 `index.html` 会因为 CORS 加载不到数据）：

```powershell
cd D:\github\Trickcal_Master\demo
python -m http.server 8791
```

然后访问 <http://127.0.0.1:8791/index.html>

> 桌面端会显示手机外壳 + 左侧页面导航；窄屏（手机上打开）自动全屏显示。

## 数据来源

全部来自 `Trickcal_crayon` v1.1.5 的真实数据，不是假数据：

- `data/characters.json` — 78 位使徒 / 702 个可解锁格（含完整棋盘布局）
- `data/petdispatch.json` — 44 只宠物 / 6 个区域 / 30 个任务
- `data/battlepower.json` — 86 位角色系数
- `assets/avatars/` — 78 张头像（webp 96px）
- `assets/pets/` — 44 张宠物图（webp 96px）

## 算法

`core.js` 里的两个引擎是从 Kotlin 原样移植的，可用来验证最终 App 的数值：

- `calcBattlePower()` — 对齐 `BattlePowerCalculatorEngine.kt`
  用 Excel 自带的样例输入验证：**762,234，与表格输出逐位一致**
- `solvePetDispatch()` — 对齐 `PetDispatchSolver.kt`
  含任务组合枚举、候选剪枝、全特阶优先 DFS、分层目标比较

### 三行筛选（对应 `AttributeCellFilterStrip` / `PersonalityFilterStrip`）
旧版算法：`cellWidth = (可用宽 - spacing*(n-1)) / n`，格子正方形，图标取 90%，
**选中/未选中只有 alpha 1.0 / 0.4**，没有背景、没有阴影、没有边框。

现在完全一致：
- 层数：3 等分，46×… 圆角 16 的按钮，选中=主色描边+主色文字
- 格子/属性：5 等分正方形，图标 88%，未选中 0.4 透明度
- **去掉了所有 focus 焦点框**，点击不会再"露出底下的按键"

   `第1层` + 该层所有属性格一行，再 `第2层`、`第3层`。单列布局，接近旧版。
2. **三行筛选改成纯图标按键** —— 不再有外层容器/卡片包裹：
   - 层数：3 个文字按钮（第 1/2/3 层）

3. **统计页压缩到一屏** —— 390×844 竖屏下 **720px 内容 / 720px 可视**，

## 和旧 App 的差异

| | 旧版 | 原型 |
|---|---|---|
| 首页 | 直接进角色列表 | 进度概览 + 子功能网格 |
| 工具入口 | 藏在设置页 | 独立 Tab |
| 筛选器 | 常驻占屏幕 | 底部抽屉 + 快捷属性条 |
| 卡片布局 | 竖排三层，一屏 1.5 个 | 两列 + 三层并排，一屏 4 个 |
| 存档 | 三种 JSON，分散入口 | 统一存档中心 |
| 格子 ID | 依赖出现序号（会漂移） | 角色+层+属性+坐标（稳定） |

## 修复的两个旧版 bug

- **任务特性覆盖串区域**：旧版 `taskBonusSkillOverrides` 用 `task.id` 做键，
  而 6 个区域的任务 id 都是 0–4，改 A 区域任务 3 的特性会同时改到其它区域的任务 3。
  原型改用 `区域名#任务id`。
- **三元表达式优先级**：原型早期版本拼 HTML 时 `a ? b : c + d` 少加括号，
  导致任务行整段丢失（已修复）。
